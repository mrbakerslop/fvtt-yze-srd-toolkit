## What changed

- Reworked Stepped Dice character creation with clear plus/minus controls, readable die ratings, and enforced Attribute and Skill allocations.
- Corrected Stepped Dice chat summaries so each die type reports its contributed successes and successful dice are coloured green.
- Updated the Push dialog to display Foundry's proper D6, D8, D10, and D12 silhouettes.
- Added an Accept Roll action that permanently locks pushing while leaving opposed rolls available.
- Arranged Accept Roll, Push Roll, and Oppose Roll into one compact, responsive action row.
- Made the Active Panic Effect panel permanently visible on Character sheets, including a clear empty state.
