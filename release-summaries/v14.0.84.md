## What changed

- Redesigned Critical Injury Items around a compact set of core fields: category, location, D6 healing time, and clear injury-state checkboxes.
- Added dedicated Attributes, Description, and Item Effects tabs to keep Critical Injury configuration tidy and easy to scan.
- Added reusable Critical Injury effects for movement restrictions, unusable limbs, blocked rolls, recurring damage, sleep restrictions, triggers, and special rules.
- Updated all 53 supplied physical and mental Critical Injuries with their appropriate locations, healing times, lethal rules, and automated effects.
- Preserved the essential death-save interval and modifier controls for lethal injuries while enforcing permanent and instant-death rules automatically.
- Added automatic migration for existing world and Actor-embedded Critical Injuries so older records adopt the new effect model safely.
- Removed visible paragraph HTML tags from descriptions throughout the supplied SRD Actor, Item, Roll Table, and Card compendiums.
- Added migration for previously imported SRD descriptions so existing world copies are cleaned when a Gamemaster next starts the world.
